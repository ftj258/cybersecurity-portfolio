# Autopsy Case Report — Sample Export

An HTML case report exported from [Autopsy](https://www.autopsy.com/), the open-source digital forensics platform built on The Sleuth Kit, following analysis of a disk image.

## What's here

This is the full report export as generated by Autopsy, covering:

- Web activity: browsing history, bookmarks, cookies, search terms, and downloads
- Email messages recovered from the image
- File-level findings: recent documents, extension mismatches, tagged/flagged files, keyword hits, and thumbnails
- EXIF metadata extracted from recovered images

`index.html` is the entry point and links out to each category above; `summary.html` has the case details.

## What this demonstrates

End-to-end use of Autopsy for media analysis — keyword searching, recovering web and email artifacts, flagging files by extension mismatch (a common way to catch disguised file types), and exporting findings into a report suitable for case documentation.
